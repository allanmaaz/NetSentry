## 🔍 Tier 3: Google Search Console (GSC) Indexing Checklist

1. **Submit Property**:
   - Open [Google Search Console](https://search.google.com/search-console).
   - Add property: `https://netsentry.pages.dev/` (URL prefix).
2. **Verify Ownership**:
   - Method 1: HTML Tag (already configured in `index.html` via `<meta name="google-site-verification" content="..." />`).
   - Method 2: Cloudflare DNS verification (TXT record in Cloudflare dashboard).
3. **Submit XML Sitemap**:
   - Go to **Sitemaps** $\rightarrow$ enter `sitemap.xml` $\rightarrow$ click **Submit**.
   - Verify status returns **"Success"**.
4. **Request Immediate URL Inspection & Crawl**:
   - Paste `https://netsentry.pages.dev/` in the URL Inspection search bar.
   - Click **"Test Live URL"** $\rightarrow$ click **"Request Indexing"** to trigger Googlebot crawl within 24–48 hours.
